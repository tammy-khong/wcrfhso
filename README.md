# Extremely Super Important Tool for Optimizing Science Olympiad Note Sheet Creation

WCRFHSO (Wikipedia Citation Remover for Hannah Science Olympiad) is an "efficient" web app that removes useless filler Wikipedia citation indcators (the square brackets with numbers inside that offer no intellectual value when visually perceiving them on paper). This permits a more productive use of paper space, since more essential knowledge can be stored on the note sheet. Consequently, productivity increases as less time is spent looking at filler.

The app takes copied and pasted Wikipedia text as a string, parses it into a vector of individual characters, and scans for square brackets, eliminating them and the numbers in between. It achieves O(n) time complexity (ignoring the character vector splitting step, time complexity unbeknownst to me), which is INCREDIBLY REMARKABLE.


Link can be found (here)[https://breadmuncher.shinyapps.io/WCRFHSO/]. Please send me lots of accolades, as I have toiled over this passion project and hope it contributes to the successes of Science Olympiad note sheets.
